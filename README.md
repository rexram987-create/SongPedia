# SongPedia

SongPedia is a smart music encyclopedia for searching artists, bands and songs.

## Version 0.1

The first prototype includes:

- One search field for artist, band or song names.
- Hebrew and English input.
- Separate result types for artists and songs.
- A simple responsive interface for desktop and mobile.
- Demo entries that verify the search flow before external APIs are connected.

## Planned data sources

Future versions can connect to:

- Wikipedia / Wikidata
- MusicBrainz
- Discogs
- The National Library of Israel
- Legal lyric-page links such as Shironet where appropriate

## Planned song details

A song page can later show:

- Performer
- Original performer
- Lyricist
- Composer
- Arranger
- Release year
- Album
- Cover versions
- Source links
- Audio recognition

## Running locally

Open `index.html` in a browser.

No build step is required for this first prototype.
